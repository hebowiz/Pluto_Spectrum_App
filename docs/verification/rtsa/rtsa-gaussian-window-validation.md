# RTSA Gaussian RBW窓とCW裾野の検証

更新日: 2026-08-30

## 現象

通常RTSAへCWを入力した際、RBWを2倍にすると搬送波から離れた裾野が約6 dB上昇した。白色雑音の測定帯域が2倍になる場合の理論値は約3.01 dBであり、同じ変化として扱うことはできない。

## 原因の切り分け

実装と数値試験を分離して確認した。

- Gaussian FFT filter bankの白色雑音ENBWは、RBW 10 kHzから20 kHzで`10 log10(2) = 3.0103 dB`増加した。電力正規化とENBW換算は正常だった。
- 従来のGaussian解析窓は無限長のインパルス応答を±4σで打ち切っていた。
- 強いCWに対する有限長窓のコヒーレント応答を測ると、遠方の数値サイドローブがRBW 10 kHzから20 kHzで約6 dB増加した。
- したがって、観測された6 dB/octの成分は白色雑音帯域ではなく、有限長Gaussian窓の端点不連続による人工的なCWリークと判断した。

## 修正

Gaussian FIR/解析窓の打ち切り範囲を±4σから±6σへ延長した。

- 端点の電圧係数を約-69 dBから約-156 dBへ低減する。
- Gaussianの両側3 dB RBW定義とENBW（約`1.0645 × RBW`）は維持する。
- RTSAのAuto FFT設計は新しい窓長を収容するNFFTを自動選択する。
- Sweep/TAとRTSAで共通のGaussian特性を保つため、共通フィルタ設計を変更する。

この変更により窓長は従来比で概ね1.5倍となる。狭RBWでは計算量と応答時間が増えるが、実用計測器として強信号の遠方裾野を人工的に持ち上げないことを優先する。

## 自動テスト

- RBW 10/20/100 kHzのAuto FFT設計で、4 MHz離調CWに対する数値リークがすべて-180 dBc未満であること。
- RBW 10 kHzから20 kHzに対するGaussian ENBW増加が3.0103 dBであること。
- Gaussian両側3 dB RBW、CW bin-center振幅、FFT support収容、連続block処理の既存仕様を維持すること。

## 実機で再確認する項目

同一CW、同一Span、同一入力レベルでRBW 10/20/100 kHzを比較する。

1. 搬送波ピークがRBWによらずほぼ一定であること。
2. 白色雑音床が約3 dB/octで変化すること。
3. 搬送波遠方の裾野に、窓打ち切り由来の6 dB/oct成分が残らないこと。
4. `Time Coverage < 100%`でもRX discontinuityを跨ぐFFTが生成されていないこと。

修正後も大きな裾野が残る場合は、Gaussian窓の数値リークではない。Pluto/信号源の位相雑音、未検出のIQ discontinuity、Detector/表示集約の順にraw IQを用いて切り分ける。
