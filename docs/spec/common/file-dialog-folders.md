# ファイル保存・読み込み時のフォルダ記憶

RTSA・VSA・VSGは、選択したファイルの親フォルダをアプリごと・ファイル用途ごとに記憶する。
次回の同じ用途のダイアログでは、そのフォルダを初期表示する。履歴はPCの設定に保存し、再起動後も復元する。

同じ種別の保存と読み込みは履歴を共有する。拡張子が同じでも用途が異なるCSVやJSONは別に記憶する。

| アプリ | 独立して記憶する用途 |
|---|---|
| RTSA | State、校正補正CSV、校正基準CSV、校正結果CSV |
| VSA | IQ記録、測定設定、既知パターン、シンボル表、VSGプロジェクト出力、DECT変調デバッグCSV、DECT電力デバッグCSV、ADS-B航空機データベースCSV、ADS-Bパケット一覧JSONL |
| VSG | プロジェクト、IQ NPZ、R&S IQ TAR、R&S WV |

- VSAのIQ記録の読み込み・出力は、各解析モードで同じ履歴を使う。
- ダイアログをキャンセルした場合は履歴を更新しない。
- 履歴がない場合、または記憶したフォルダが存在しない場合は、用途の既定フォルダか作業フォルダを開く。
- 保存時のファイル名候補と対応形式は従来どおり。
- VSAの設定画面内で開いたファイルのフォルダも記憶する。設定画面のキャンセルによって測定設定を破棄しても、フォルダ履歴は残す。

共通処理は `pluto_common/file_dialogs.py`。履歴には既存の各アプリの `QSettings` を使用し、測定設定ファイルには含めない。
