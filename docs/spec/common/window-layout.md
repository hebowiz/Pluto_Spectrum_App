# ウィンドウ位置・サイズとペイン配置

RTSA / VSA / VSGの共通仕様。周波数校正アプリは対象外。

## メインウィンドウ

- 初期指定サイズは従来どおり1600×960。明示的な最小サイズは全アプリ960×640。
- 正常な終了処理で位置・サイズを保存し、次回起動時に復元する。
- 保存キーは各アプリの既存QSettings内の`startup/geometry`。
- 復元にはQtの`restoreGeometry()`を使う。画面領域や最大化状態の扱いもQtに委ねる。
- 保存情報がない場合の出現位置は従来どおりOS / Qtに委ねる。
- VSGの既存`startup/geometry`はそのまま利用する。
- 初期サイズ、操作パネルの幅240、測定設定の保存先・保存内容は維持する。

共通処理: `pluto_common/window_geometry.py`。
VSGのクラス単体では従来どおり`restore_startup_state=False`が既定値であり、
通常の起動入口は`True`を渡す。無効時でも最小サイズは適用する。

## 内部レイアウト

| 項目 | RTSA | VSA | VSG |
|---|---|---|---|
| ペインの移動・別窓化 | 不可 | 可 | 可 |
| ペインを閉じる操作 | 従来のGraph Viewで表示を選択 | 無効 | 無効 |
| 内部配置・分割比率の再起動時復元 | なし | なし | なし |
| 選択タブの永続保存 | なし | なし | なし |
| リサイズ時の明示的な再均等化 | なし | なし | なし |

再均等化しない場合も、ウィンドウサイズに応じたQtの通常の伸縮と、
各部品の最小寸法による調整は行われる。
初回のサイズ配分は適用するが、リサイズするたびに適用し直さない。

RTSAの測定モード・Graph Viewの保存は継続する。
これはペインの位置や分割比率の保存とは別の機能。

## VSAのモード切替

- 起動時にGeneral VSA / Bluetooth / DECT / ADS-Bの画面を生成し、General VSAを表示する。
- モードを離れる直前に、その画面のドック配置・分割サイズ・フローティング状態を
  メモリー上に保存する。
- 別窓化したペインは非アクティブなモードでは隠し、元のモードへ戻ると復元する。
- 同じ実行中にモードを切り替える場合は、保存したレイアウトを復元する。
- これらの状態はQSettingsや測定設定ファイルには書かない。再起動時は初期配置。
- 同じモードを再選択しても均等化しない。
- ADS-Bのリサイズイベントによる再均等化は廃止する。
- 初期の3列×2段の内容と、各モードの初期サイズ配分指定は従来どおり。

## VSGのペイン

ワークスペースをドック方式に変更する。各ペインはドラッグで再配置、
タブ化、別窓化できる。右操作パネルは従来どおり固定幅のまま。

| 領域 | 上段 | 下段 |
|---|---|---|
| 左 | Block Library + Packet Composer | Generated IQ Preview |
| 右 | Inspector | Packet Decode |

初期のサイズ配分は左:右が概ね2:1、各領域の上下が1:1、
左上のBlock Library:Packet Composerが概ね1:3。
部品の最小寸法等によって実寸は調整される。
内容・タブ構成・プロジェクト生成・送信操作は維持する。

旧`startup/window_state`は復元せず、保存時に削除する。
メインのgeometryのみを保存し、ドック配置や選択タブは保存しない。

## 終了時

VSAの取得・解析、VSGの準備・送信を停止してから終了する既存処理を維持する。
終了が受理された時点でgeometryを保存し、別窓化したペインも隠す。
終了を待機している間にレイアウトを初期化する処理は行わない。

## 検証

`tests/test_window_layout.py`で以下を確認する。

- 3アプリのgeometry保存・復元、表示後の960×640への縮小。
- 不正なgeometry設定からの起動。
- VSAのモード別分割サイズ・ドック配置・別窓の復元と、再起動時の初期化。
- VSA全モードでリサイズ・モード復帰時に均等化しないこと。
- VSGのドック操作、再起動時の配置・選択タブ初期化。
- アプリ終了後にフローティングペインが残らないこと。
