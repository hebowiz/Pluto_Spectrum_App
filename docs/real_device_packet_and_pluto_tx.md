# Plutoによるパケット送信検証
- PSKのピークレベルでdBFSが決まるので、FSKとの相対レベル次第でFSK部のレベルが変わる
- 多パケット時は全部プロットすると重すぎるので、3パケット目以降は表示省略がいい
- 送信ボタン押した後2秒程度経過してから650ms程度の間0dBm（ゲイン指定に依存しない）のバースト出力があった後、指定パケット送信が発生する
- ゲイン0dB指定で-6.4dBm程度（公称出力+7dBmなのでもっと出せるはず？）
- ゲイン-10dB指定で-15.5dBm
- ゲイン-20dB指定で-25.3dBm
- R&S VSGはパケット全体のパワー平均値で規格化してそう（2DH1のFSKとPSKのパワーを同じに設定するとFSK部のパワーがDH1と同じになる）
