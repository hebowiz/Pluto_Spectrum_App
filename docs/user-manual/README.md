## 共通の注意

- 本ソフトウェアとADALM-Plutoは、校正済み計測器の代替を保証するものではありません。
- アンテナから送信する場合は、使用地域の電波法令、周波数割当、免許条件を確認してください。
- 信号源をケーブル接続する場合は、Plutoの入力定格を超えないよう外部アッテネータを使用してください。
- 同じPlutoを複数アプリから同時に使用することはできません。タイトルバーのRX/TX識別表示を確認してください。
- 実装中または規格原典との照合が完了していない測定項目は、適合判定の唯一の根拠にしないでください。

スクリーンショットは送受信を行わないプレビュー環境で生成しています。表示値や空のグラフは操作説明用で、測定結果を表すものではありません。
