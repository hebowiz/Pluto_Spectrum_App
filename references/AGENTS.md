# External reference material

- This directory stores external/vendor publications, original standards, and user-provided material. Do not place Codex-generated project designs here.
- Existing reference files are read-only by default. Do not edit their content or silently correct apparent errors.
- Read only the reference material needed for the task.
- Keep original source content separate from project interpretation and design decisions; record the latter under `../docs/`.
- Preserve provenance, filenames, and any existing Git exclusion restrictions when moving material. Do not assume a document's origin from its filename alone.
- Use `vendor/<vendor>/`, `standards/<protocol>/`, or `user-input/` as appropriate. Add empty categories only when needed.
